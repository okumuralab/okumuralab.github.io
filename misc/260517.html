findの代わりにfdを使う

fd はRustで書かれた現代版findです。

Homebrewの入ったMacなら brew install fd でインストールできます。Alma Linuxでは sudo dnf install fd-find でインストールできました。

単に fd hoge と打ち込めば、カレントディレクトリ以下にある hoge.txt や foohogebar.md など hoge を含むファイル名を列挙してくれます。

パターンは正規表現ですので、hoge.txt だけを見つけたい場合は fd '^hoge\.txt$' のようにします。

拡張子が zip のファイルを全部見つけるには fd '\.zip$' でもいいのですが、fd -e zip という書き方もできます。

fd -e zip -x unzip とすれば、カレントディレクトリ以下のすべてのzipファイルを個々にunzipします。
