PLaMoのAPIを使う

PLaMo は Preferred Networks（プリファードネットワークス、PFN）による国産のLLMである。API 料金は入力300円/Mトークン、出力1000円/Mトークンで、ほぼ GPT-4.1 並である。現在、登録すれば1000円分のクレジットがもらえる。

登録するとAPIキーが発行されるので、環境変数に

export PLAMO_API_KEY="..."

のようにして登録しておくと便利である。OpenAIのChat Completions APIと互換性があるので、OpenAIのAPIを使うのコードがそのまま利用できる：

chatbot = Chatbot(model="plamo-1.0-prime")
chatbot.chat("まどマギでだれが好きですか？")
