PLaMoをMLXで

Hugging FaceのMLX PLaMoモデルの中で、自分のメモリサイズに合ったモデルを試してみる。ここでは mlx-community/plamo-2-8b-bf16 を使う。

pip3 install --upgrade mlx_lm numba
python3 -m mlx_lm generate \
    --model mlx-community/plamo-2-8b-bf16 \
    --prompt '## 美味しいカレーの作り方:\n' \
    --ignore-chat-template \
    --max-tokens 2048 \
    --extra-eos-token '<|plamo:bos|>' \
    --temp 0.7 \
    --seed 0

と打ち込むと、カレーの作り方が詳しく表示される。

Pythonでプログラムを書いて使うには、例えば次のようにする。

from mlx_lm import load, generate

model, tokenizer = load("mlx-community/plamo-2-8b-bf16",
                        tokenizer_config={"trust_remote_code": True})
tokenizer.add_eos_token("<|plamo:bos|>")

prompt = r'''## 美味しいカレーの作り方:
'''

response = generate(
    model, 
    tokenizer, 
    prompt=prompt,
    max_tokens=512,
    verbose=True,
)

# print(repr(response))
