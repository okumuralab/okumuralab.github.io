MacのTime Machineの整理

MacのTime Machineとして使っている4T SSD（APFSボリューム）が満杯になった。

古いバックアップを削除するには、Finderで該当の日付のものを右クリックして削除を選ぶだけである。

ターミナルでやるには、次のようにする。まずターミナルにフルディスクアクセス権がなければ付けておき、次のコマンドを打つ：

sudo tmutil listbackups -t

これでタイムスタンプがリストされる：

2024-12-13-073100
2024-12-20-082804
2024-12-27-083209
...

Time Machine用SSDが /Volumes/hoge だとすると、次のようにして削除できる：

sudo tmutil delete -d /Volumes/hoge -t 2024-12-13-073100 
sudo tmutil delete -d /Volumes/hoge -t 2024-12-20-082804
sudo tmutil delete -d /Volumes/hoge -t 2024-12-27-083209
...
