## Marpとは

Markdownでプレゼンテーションスライドを作るための仕組みです。
`---` が改ページです。最初のYAML部分は設定です。

- 箇条書きは `-` または数字で始めます。
  - スペース2個でネストできます。
  - `*` で始めると1個ずつ表示されます。

1〜3個の `*` で囲んで *Italic*、**Bold**、***Bold Italic*** にできます。

> 引用は `>` で始めます。

このファイルがサンプルです。
新しいフォルダにこのファイルを `index.md` という名前で保存してお試しください。

---

## Mac/Homebrewでのインストール

```
brew install marp-cli
```

更新は `brew update && brew upgrade`


あるいは `brew install node` した環境で

```
npm install -g @marp-team/marp-cli
```

更新は `npm update -g`

バージョン確認: `marp --version`

---

## ブラウザでの利用

このファイルのあるディレクトリで次のように打ち込みます：

```
marp . --server
```

ブラウザで http://localhost:8080/ を開きます（もしファイル名がリストされたらファイル名をクリックします）

---

## HTML/PDF/PowerPointファイルへの変換

```
marp index.md --html

marp index.md --pdf

marp index.md --pptx
```

それぞれ `index.html`、`index.pdf`、`index.pptx` ができます。

---

## 画像の入れ方

```
![](https://okumuralab.org/~okumura/img/okumura130506.jpg)
```

`[]` にはオプションが入ります。例：

```
![bg fit left:40%](logo.svg)
```

HTMLの `img` タグも使えます。

ローカルの画像を使ってPDF/PowerPointにするには `--allow-local-files` が必要です：

```
marp index.md --pdf --allow-local-files
```

## テーマ

`theme` は `default`、`gaia`、`uncover` が設定できます。

```
---
paginate: true
theme: gaia
---
```

さらに `class: invert` で白黒反転します。
