Unsloth Studio

Unsloth StudioはWebブラウザでローカルLLMを使うための仕組みです。

  • https://github.com/unslothai/unsloth
  • Introducing Unsloth Studio

推奨インストールの仕方は何度も変わっています。上記最初のリンクを参照してください。以下は開発者用のインストールの仕方です:

git clone https://github.com/unslothai/unsloth
cd unsloth
# 不安定版: git checkout nightly
./install.sh --local

更新:

cd unsloth
git pull
unsloth studio update --local

サーバ起動:

unsloth studio -H 0.0.0.0 -p 8888 &

ブラウザで http://localhost:8888 を開くとUnsloth Studioの画面が現れます。Select model... からQwen3.5-4B-GGUFを選んで実行してみましょう。うまくいったら、もっと大きいモデルを試してみましょう。

私の環境だけの問題かもしれませんが、外付けのやや遅いSSDを使っているためか、大きいモデルを選ぶとタイムアウトしてしまうことがありました。再度試してもうまくいかないなら、ターミナルのメッセージに ~/.unsloth/llama.cpp/build/bin/llama-server を実行するコマンドが表示されますので、そのコマンドだけ打ち込んで単独で実行し、うまくいけば Control-C で止めます。これでキャッシュされて、次回は速くロードされ、うまくいきます。

コードを書き換えてタイムアウト値を大きくするには、studio/backend/core/inference/llama_cpp.py の if not self._wait_for_health(timeout = 120.0): の値を増やし、さらには studio/backend/core/inference/orchestrator.py の resp = self._wait_response("loaded", timeout = 180) の値を増やすと良さそうです。ソースは頻繁に更新されますので、うまくいかなければコーディングエージェントに聞いてください。
