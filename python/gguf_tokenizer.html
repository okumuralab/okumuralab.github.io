GGUFモデルのトークナイザ

GGUFモデルを扱うための llama.cpp は、Homebrewでは brew install llama.cpp でインストールできる。これに含まれる llama-tokenize コマンドで文字列をトークンに分割できる。llama-tokenize --help で使い方がわかる。例えば

llama-tokenize --stdin -m /path/to/gemma-4-31B-it-UD-Q8_K_XL.gguf

と打ち込んで、標準入力に文字列・文章を打ち込み、Ctrl-D すれば、トークン分割した結果が表示される。

llama-tokenize にはトークンの語彙を一覧する機能はなさそうなので、Codexに書いてもらったのが dump_gguf_vocab.py である。これで

./dump_gguf_vocab.py -m /path/to/gemma-4-31B-it-UD-Q8_K_XL.gguf -o vocab.txt --format plain

としてできる vocab.txt を使って、日本語っぽい語彙の長いものを抜き出してみる：

import re

japanese_re = re.compile('[\u3000-\u30ff\u4e00-\u9fff\uf900-\ufaff]')

with open('vocab.txt') as f:
    vocab = [line.rstrip('\n') for line in f]

vocab.sort(key=len, reverse=True)

for w in vocab[:100000]:
    if japanese_re.search(w):
        print(repr(w))
