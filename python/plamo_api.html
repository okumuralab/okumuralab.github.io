PLaMoのAPIを使う

PLaMo は Preferred Networks（プリファードネットワークス、PFN）による国産のLLMである。2025年5月22日、PLaMo 2.0 Primeが出て、古いPLaMo 1.0 Primeは提供終了になった。PLaMo 2.0 Primeの API 料金は、入力60円/Mトークン、出力250円/Mトークンで、gpt-4.1-mini並である。現在、登録すれば1000円分のクレジットがもらえる。すべてのリクエストが日本国内のサーバーで処理される。

登録するとAPIキーが発行されるので、環境変数に

export PLAMO_API_KEY="..."

のようにして登録しておくと便利である。OpenAIのChat Completions APIと互換性があるので、OpenAIのAPIを使うのコードがそのまま利用できる（エンドポイントは https://api.platform.preferredai.jp/v1）：

chatbot = Chatbot(model="plamo-2.0-prime")
chatbot.chat("まどマギでだれが好きですか？")

詳しくはドキュメントを参照されたい。
