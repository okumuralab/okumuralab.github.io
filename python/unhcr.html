UNHCRのグラフィックス

国連 UNHCR Dataviz Platform が話題になっていた。

例えば Bar chart（棒グラフ）には「Always start at a zero baseline.」（必ず0から始めよ）、Pie chart（円グラフ）には「Include between two to five categories.」（カテゴリ数は2〜5に）といったことが書かれている。

Tutorials には R、Matplotlib、Plotly Python、D3 による解説がある。

Matplotlib については unhcrpyplotstyle というパッケージが提供されている。pip install unhcrpyplotstyle でインストールできる。
